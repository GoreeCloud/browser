# GoreeCloud Browser Branding

**Current authority:** `GoreeCloud/branding-assets`; canonical Browser product asset: `products/browser/app-icon.svg`.

Verified central source: Git blob `3f502e5a6dae8ff3cb86dfdc3ae5d2eb2e8b54e1` on `GoreeCloud/branding-assets` `main`, confirmed September 23, 2026. Its approved catalog artwork is the blue compass-style Browser icon, following the September 8 unified-mobile icon update. The former Tabmark materials in this repository predate that central authority and must not be promoted as the current approved artwork.

`assets/branding/goreecloud-browser.svg` is an exact, build-time consumer copy of that central source, checked by the Android launcher source guard against the recorded Git blob. `assets/branding/goreecloud-browser-monochrome.svg` is a simplified monochrome consumer derivative preserving the central ring/needle geometry. It is **not independently approved or device-accepted** merely because the source geometry matches.

Android drawable/adaptive resources remain packaging derivatives, not independent masters. Exact APK resource presence and app identity are separately checked by Android CI. Proper rendering in GoreeCloud Launcher and Trebuchet on supported physical devices, mask/theme contrast, correct optical size, and actual Browser usability remain outstanding in Browser issue #33. Branding/provenance alignment does not establish Privacy Shield/Wardveil acceptance, release approval or Stable status.
