# GoreeCloud Browser

A maintained Mozilla Firefox/Gecko **Fork-to-Native development candidate** based on Firefox 158.0 Stable.

This repository retains upstream licensing and attribution. See `LICENSE`, `goreecloud/upstream/BASELINE.json`, and `goreecloud/README.md` for origin and integration boundaries.

**Not yet a distributable GoreeCloud browser.** Glaze, product branding, service adapters, migration from the current CEF/Chromium Browser, compiled builds, security and privacy testing, accessibility, packaging, and release validation remain pending. See `goreecloud/RELEASE-GATES.md`.
